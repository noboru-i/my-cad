# keyboard_trackpad_tray v3

Magic Keyboard + Magic Trackpad トレイ。5mm リブ + 10mm レールの十字相欠き格子をデッキ板でロックするトーションボックス構造は v2 を踏襲しつつ、**前縁レール R1 系を廃止**し、パームレストを机に自立するユニットに再設計した。**Bambu Lab A1 mini の 4 プレートで全パーツを印刷できる。**

## v2 使用フィードバックによる変更点

1. **キーボードに傾斜をつけたい（交換パーツで調整）** → デッキ後端に**ライザーバー（T{h}R / T{h}L）**を新設。デッキの穴にタブを差し込むだけの平置き印刷パーツ 2 本で、`riser_h` を変えて刷り直せば傾斜を変更できる。傾斜はデッキ前縁（y=12.9）を支点に後端が `riser_h` 持ち上がる（4mm ≈ 2.8°、8mm ≈ 5.6°）。`riser_h=0` ならライザーなしのフラット。前リップ・横ストップ・後端タブは `riser_h=8` まで掛かりが残る高さにしてあり、assert で保証している
2. **トラックパッド左右の重なりを交換パーツで制御（物理パームリジェクション）** → パームレスト板（WR/WL）に**トラックパッド上へ張り出すフラップ**を追加。開口幅は `tp_exposed_w`（初期値 130mm）。フラップ下面 10.5mm はトラックパッド後端の楔形より常に 1mm 以上高い（assert 済み）。幅を変えたいときは WR/WL だけ刷り直す
3. **トラックパッドの操作奥行きを 9cm に、それ以降はキーボードを重ねる** → `tp_exposed_d`（初期値 90mm）からキーボード前縁位置を導出（kb_front = -12.5）。デッキ前縁はトラックパッドに届かない位置で止め、重なり部分はキーボード本体の張り出しのみ
4. **R1 系が外れやすい** → **R1L/R1C/R1R を廃止**。机接地の前壁とトラックパッド前リップを WR/WL に一体化し、パームユニット自体が机に立つ。左右は中央前帯の**上から落とすだけの蟻継ぎ**で連結し、リブのほぞ（各 3 本）が板の穴を貫通してロックする。下にぶら下がる部材がなくなったので脱落しない

## 寸法ソース

2026-06-22 に Apple Store の Tech Specs から取得。

- Magic Keyboard (USB-C): 278.9 × 114.9 × 4.1–10.9 mm
- Magic Trackpad (USB-C): 160.0 × 114.9 × 4.9–10.9 mm

トラックパッドは机に直置き、キーボード面はデッキ板上面の 12.6mm（+ライザー傾斜）。

## パーツ構成（15 + ライザー 2）

各ピースには識別コードが彫り込んである（深さ 0.6mm）。同じ記号同士を蟻継ぎで連結する。数字は 1=手前 / 2=奥。

| 刻印 | ピース | 数 | 説明 |
|---|---|---|---|
| A1 / A2 | outer_front / outer_rear | 各2 | 外壁リブ。ほぞが横ストップを兼ねる。机に全長接地 |
| B1 / B2 | stop_front / stop_rear | 各2 | トラックパッド横壁リブ。前部はパームユニットを載せる棚（z=7） |
| C | center | 1 | 中央リブ（継ぎ目なし） |
| R2 | tpstop_rail | 1 | トラックパッド後方ストップ兼デッキ前縁支持。中央に USB-C プラグ用ブリッジアーチ |
| R3 / R4 | mid_rail / rear_rail | 各1 | 中間・後部レール（ケーブル窓・R4 は接地パッド付き） |
| WL / WR | wrist_l / wrist_r | 各1 | パームユニット。前壁・トラックパッド前リップ・パームフラップ一体、机に自立。中央で蟻継ぎ連結（刻印は裏面） |
| DL / DR | deck_l / deck_r | 各1 | キーボードデッキ板。全リブ・全レールのほぞを閉じた穴で捕捉（刻印は裏面） |
| T{h}L / T{h}R | riser_l / riser_r | 各1 | 傾斜ライザー。h はミリ高さ（T4R など）。タブ 2 本がデッキの穴に入る。riser_h=0 なら不要 |

**継ぎ目の位置**: A リブは y=40（デッキ板のほぞ穴が両側から挟む）、B リブは R2 のスロット内、WR/WL は中央前帯（x=0、上から落とす向きの蟻）。

## パラメータ（交換パーツの作り方）

| 変数 | 初期値 | 対象パーツ | 効果 |
|---|---|---|---|
| `riser_h` | 4 | riser_r / riser_l | キーボード後端の持ち上げ量。0 でフラット、8 まで検証済み |
| `tp_exposed_w` | 130 | wrist_r / wrist_l | フラップ間のトラックパッド開口幅。140 まで検証済み |
| `tp_exposed_d` | 90 | 全体（要フル再印刷） | トラックパッド前後の操作奥行き |

例: 8mm ライザーだけ出力する場合

```bash
openscad --render -D 'part="riser_r"' -D 'riser_h=8' -o stl/riser_r_h8.stl keyboard_trackpad_tray_v3.scad
```

## STL 生成と印刷

```bash
./render_stl.sh   # stl/plate1.stl .. stl/plate4.stl + 8mm ライザー
```

- plate1: DR + R2 + R3 + R4 + C / plate2: DL + A1×2 + B1×2 / plate3: WR + A2×2 + T4R + T4L / plate4: WL + B2×2
- 各プレートは 178×178mm 以内（`part="check_fit1..4"` が空レンダリングになることで保証。2D なので確認時は SVG に出力する）
- 推奨: 0.2mm layer, 4 walls, infill 40% 以上
- 全パーツ平置き・サポート不要。ブリムなし推奨（ピース間隔 1.5mm のため）
- **WR/WL はプレート上で上下反転**（パーム面が下、前壁・リップが上向きのリブになる向き）で全面接地する。刻印が上を向いていれば正しい姿勢

## 組み立て

1. 蟻継ぎを板厚方向へ横からスライドして連結：A1+A2 を2組、B1+B2 を2組
2. レール R2・R3・R4 を置き、リブを上から十字に差し込む。A が両外、B がその内側、C は R3/R4 のみに差さる。**B の継ぎ目が R2 のスロットに入ることを確認**
3. デッキ板 DL/DR を上から押し込む。全リブ・レールのほぞが穴に入り、格子がロックされる
4. **トラックパッドを先に前中央のポケットへ置く**（パームユニットのフラップが上に被さるため、後からは入らない）
5. パームユニット WR を B・A リブの棚に載せてほぞを穴に通し、WL を同様に載せながら中央の蟻継ぎを上から落として連結する
6. ライザー T{h}R / T{h}L をデッキ後端の穴に差し、キーボードをデッキ（前縁は前リップ、後端はライザー上）に載せる。riser_h=0 のときはそのままデッキに置く

きつい場合は `slot_clearance` / `splice_clearance` / `tenon_clearance` を増やして再出力する。

## メモ

- トラックパッドの充電プラグは R2 中央のブリッジアーチ（幅20×高9.5）を通してキーボード下へ。ケーブルは R3/R4 の窓（x=+25）から背面へ抜ける
- パームレスト上面は 13.5mm（デッキより 0.9mm 高い、意図した設計）
- 検証用 part: `assembly` / `check_fit1..4`（2D、SVG 出力）/ `check_interference`（デバイス非接触）/ `check_lattice`（相欠き非干渉）/ `check_skins`（ほぞと板の非干渉）/ `check_riser`（ライザーと格子の非干渉）— check 系はすべて空レンダリングが合格。`riser_h=0/4/8`、`tp_exposed_w=140` で確認済み
