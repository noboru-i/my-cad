# keyboard_trackpad_tray v3

Magic Keyboard + Magic Trackpad トレイ。5mm 厚のリブ格子と **10mm 厚のレール**を十字相欠きで組み、その上に**2枚の天板スキン（デッキ板）とリストレスト板**を被せてトーションボックス化する構造。**Bambu Lab A1 mini の 3 プレートで全パーツを印刷できる。**

## v2 印刷のフィードバックによる再設計

v2 は「4つ組んでも全然強度が出ない（ぐらぐら）」「R1 が細く頼りない」だった。原因と対策：

1. **ねじれ止めの欠如** → キーボードの下に**デッキ板（DL/DR）を新設**。リストレスト板で好評だった「通しほぞ + 閉じた穴」のロックを全部材に拡張し、デッキ板がすべてのリブ・レール・継ぎ目を上から固定する。キーボードはリブの木口ではなくデッキ板の面に載る
2. **A1/A2 の継ぎ目が空スロット上にあった**（R2 は外壁リブまで届いていない）→ 外壁リブの継ぎ目を y=40 に移し、継ぎ目の両側のほぞをデッキ板の穴に通して挟み込む
3. **レールが細い** → 板厚を 5mm → **10mm** に倍増。蟻継ぎも 10mm 幅になり大幅に強化
4. **R1（前縁レール）が頼りない** → 10mm 厚化に加え、ほぞでリストレスト板に直結。継ぎ目は従来どおり B リブのスロット内で、上からリストレスト板が押さえる
5. **R2/R3/R4 は ±88mm に短縮して継ぎ目なしの 1 本物に**（外周の拘束はデッキ板が担う）。ピース数 21 → 19

## 寸法ソース

2026-06-22 に Apple Store の Tech Specs から取得。

- Magic Keyboard (USB-C): 278.9 × 114.9 × 4.1–10.9 mm
- Magic Trackpad (USB-C): 160.0 × 114.9 × 4.9–10.9 mm

トラックパッドは机に直置き、キーボード面はデッキ板上面の 12.6mm。

## パーツ構成（19 ピース）

各ピースには識別コードが彫り込んである（深さ 0.6mm）。同じ記号同士を蟻継ぎで連結する。数字は 1=手前 / 2=奥。

| 刻印 | ピース | 数 | 説明 |
|---|---|---|---|
| A1 / A2 | outer_front / outer_rear | 各2 | 外壁リブ。ほぞが横ストップを兼ねる。机に全長接地 |
| B1 / B2 | stop_front / stop_rear | 各2 | トラックパッド横壁リブ |
| C | center | 1 | 中央リブ（継ぎ目なし） |
| R1L/R1C/R1R | front_rail_* | 各1 | 前縁レール 10mm 厚。トラックパッド前リップ・接地パッド・リストレスト板へのほぞ付き |
| R2 | tpstop_rail | 1 | トラックパッド後方ストップ兼デッキ前縁支持。中央に USB-C プラグ用ブリッジアーチ |
| R3 / R4 | mid_rail / rear_rail | 各1 | 中間・後部レール（ケーブル窓・R4 は接地パッド付き） |
| WL / WR | wrist_l / wrist_r | 各1 | リストレスト板。R1 のほぞ穴と A/B リブの切り欠きで前部をロック（刻印は裏面） |
| DL / DR | deck_l / deck_r | 各1 | キーボードデッキ板。全リブ・全レールのほぞを閉じた穴で捕捉し格子をロック（刻印は裏面） |

**継ぎ目の位置**: A リブは y=40（デッキ板のほぞ穴 2 個が両側から挟む）、B リブは R2 のスロット内、R1 は B リブのスロット内（＋リストレスト板が押さえる）。

**蟻継ぎの形状（v3 初回スライスで修正）**: 当初はソケットの斜め上辺がプロファイル上端 `h_sub` に達していたため、クリアランス `offset` 込みで上端を突き抜け、ソケット上の「フック」が一点接続の破片としてスライスされていた（A2/B2 の左端に脱落した欠片が出る）。蟻継ぎ上辺を下げてフックに常に 1.25mm 以上の肉を残し、A リブはソケット下端も底面まで切り下げて 0.25mm のヒゲを解消（A1 のタブは机に接地）。抜け止めの勾配は維持。

## STL 生成と印刷

```bash
./render_stl.sh   # stl/plate1.stl .. stl/plate3.stl
```

- 各プレートは 178×178mm 以内（`part="check_fit1/2/3"` が空レンダリングになることで保証）
- 推奨: 0.2mm layer, 4 walls, infill 40% 以上
- 全パーツ平置き・サポート不要。ブリムなし推奨（ピース間隔 1.5mm のため）

## 組み立て

1. 蟻継ぎを板厚方向へ横からスライドして連結：A1+A2 を2組、B1+B2 を2組、R1L+R1C+R1R
2. レール R1・R2・R3・R4 を置き、リブを上から十字に差し込む。A が両外、B がその内側、C は R3/R4 のみに差さる。**B の継ぎ目が R2 のスロットに、R1 の継ぎ目が B のスロットに入ることを確認**
3. デッキ板 DL/DR を上から押し込む。全リブ・レールのほぞが穴に入り、格子全体がロックされる。外壁リブの長いほぞ（4本）はデッキ面から 4mm 突き出てキーボードの横ストップになる
4. リストレスト板 WL/WR を上から押し込む（R1 のほぞが穴に、リブのほぞが縁の切り欠きに入る）
5. トラックパッドを前中央のポケットへ落とす（机に直接接地）。キーボードはデッキ板に載せる

きつい場合は `slot_clearance` / `splice_clearance` / `tenon_clearance` を増やして再出力する。

## メモ

- トラックパッドの充電プラグは R2 中央のブリッジアーチ（幅20×高9.5）を通してキーボード下へ。ケーブルは R3/R4 の窓（x=+25、下弦 2mm を残した開口）から背面へ抜ける。キーボードは背面からそのまま充電可
- リストレスト板の上面（12mm）はトラックパッド面より高い（意図した設計）
- 検証用 part: `assembly` / `check_fit1..3` / `check_interference`（デバイス非接触）/ `check_lattice`（相欠き非干渉）/ `check_skins`（ほぞと板の非干渉）— check 系はすべて空レンダリングが合格
