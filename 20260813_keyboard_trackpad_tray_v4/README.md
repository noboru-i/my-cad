# keyboard_trackpad_tray v4

03enterprise 製「Crispy Backboard PRO 2021」風のキーボードトレイ。アクリル板だった実物に対し、位置決めリブとキーボードのゴム足凹みを一体成形するパラメトリック設計に置き換えた。v3（トーションボックス格子）とは別系統のシンプルな板構成で、BOSL2 は使用しない。

## コンセプト

- ベース板1枚（奥＝キーボード載置部、手前中央＝トラックパッド用の貫通切り欠き）＋左右対称のリストレスト2枚の構成
- トラックパッドは机に直置き。ベース板がトラックパッド後端の上に `tp_overlap` 分だけ被さり、キーボードとトラックパッドの奥行きを共有する
- リストレストはトラックパッド左右を `rest_tp_cover` 分覆い、内側上部を `rest_chamfer_angle` で斜めカットして操作域を確保する
- `tp_angle` > 0 のときだけ、トラックパッド下に敷く傾斜ウェッジ（別パーツ）で角度を付けられる
- ベース天面の凸ペグ（左右2箇所ずつ）とリストレスト側の貫通穴で位置決め。ウェッジ等の固定機構はなく、前後・左右方向のズレ止めのみ（持ち上げ方向は自重で保持）。ペグ位置は外側端 (x=0) 基準で固定しているため、`rest_tp_cover` の異なる複数サイズのリストレストを印刷しておいても同じベースに差し替えて使える

## 寸法ソース

- 本体全体 280 × 214 × 16mm、ベース6mm、リストレスト4mm（03enterprise Crispy Backboard PRO 2021 製品ページ）
- Magic Keyboard: 279 × 114.9 × 4.1–10.9mm（Apple / Wikipedia）
- Magic Trackpad 2: 160 × 114.9 × 4.9–10.9mm（Apple / Wikipedia）

## パーツ構成（`part` パラメータ）

| part | パーツ | 説明 |
|---|---|---|
| 0 | Assembly | プレビュー用。ベース＋左右リストレスト（＋傾斜ウェッジ）を組み立てた状態で表示 |
| 1 | Base | ベース板。`split_base=true` なら中央 x = board_w/2 に幅0.4mmのスリットを通し、左右2つの独立したソリッドに分離する（1つの STL に2シェルとして出力。多くのスライサーは自動で別オブジェクトとして認識する） |
| 2 | WristRest_L | リストレスト左 |
| 3 | WristRest_R | リストレスト右（`wrist_rest(-1)` を X ミラーしたもの） |
| 4 | TiltWedge | トラックパッド下の傾斜ウェッジ。`tp_angle=0`（初期値）だと空レンダリングになる |

## 主要パラメータ

| 変数 | 初期値 | 効果 |
|---|---|---|
| `tp_overlap` | 16 | ベース（キーボード載置部）がトラックパッド後端上を覆う量。0〜40mm |
| `tp_angle` | 0 | トラックパッド傾斜角。0なら水平でウェッジ不要。0〜15度 |
| `rest_tp_cover` | 20 | リストレストがトラックパッド左右端を覆う量。0〜60mm |
| `rest_chamfer_angle` | 30 | リストレスト内側上部の斜めカット角。0〜60度 |
| `rest_d` | 98 | リストレスト奥行 |
| `base_t` / `rest_t` | 6 / 4 | ベース板厚 / リストレスト板厚 |
| `margin` | 0.5 | デバイス周囲の遊び（片側） |
| `lip_w` / `lip_h` | 3 / 2.5 | キーボード位置決めリブの幅・高さ |
| `corner_r` | 4 | 外形コーナーR |
| `kb_foot_d` / `kb_foot_dep` | 9 / 0.8 | キーボードゴム足凹みの直径・深さ（要実測） |
| `kb_foot_inset_x` / `kb_foot_inset_y` | 15 / 8 | ゴム足凹みの左右・前後端からの距離（要実測） |
| `split_base` | true | ベース板を中央スリットで2分割するか（A1 mini など280mm未満のベッド向け） |
| `peg_d` / `peg_h` | 6 / 3.7 | 位置決めペグの直径・高さ（`rest_t` よりわずかに低く、天面から突き出さない） |
| `peg_inset_x` | 14 | ペグの外側端 (x=0) からの距離 |
| `peg_ys` | [20, 78] | ペグのY位置（外側端基準、2点で回転もロック） |
| `peg_clearance` | 0.3 | リストレスト側の穴クリアランス（直径に加算） |

ゴム足の位置・直径は実機での実測を推奨（コメントに「要実測」とある通り初期値は仮）。

## STL 生成と印刷

```bash
./render_stl.sh   # stl/base.stl, stl/wrist_rest_l.stl, stl/wrist_rest_r.stl
```

- Bambu Lab A1 mini（ビルドプレート 180×180mm）を想定。`board_w`（既定値で約286mm）は `split_base=true` のままレンダーすることで左右2分割され、各片が約143mm幅に収まる
- `tp_angle` を変更して傾斜を付けたい場合は、ウェッジも合わせて出力する

```bash
openscad --render -D 'part=4' -D 'tp_angle=8' -o stl/tilt_wedge_a8.stl keyboard_trackpad_tray_v4.scad
```

- レンダー時にターミナルへ全体寸法（`board_w × board_d`）が echo される
- 位置決めリブ・キーボードゴム足凹みは印刷方向そのままで全パーツ平置き・サポート不要

## メモ

- `show_devices=true` にするとプレビューにキーボード・トラックパッドのダミー形状（半透明）が重なって表示される
- ベース板のトラックパッド被さり部分は `overhang_t()` で最低1.2mm厚を確保し、トラックパッド後端と干渉しないよう逃がしている
