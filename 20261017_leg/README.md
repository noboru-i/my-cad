# leg

底面 290 × 48mm の箱型の物を、左右2本で支える足。A1 mini（180 × 180 × 180mm）で全長290mmを一体で造形できないため、両端を別々の足で支える。

## 形状

- 天面に、コの字型のズレ止めの壁を付けた。外側端と長辺の2面を囲み、中央側を開けている。
- 高さを出す柱は中空にした。4面の壁には、千鳥配置の菱形の窓を開けている。
- 柱内部の天井は45°の寄棟形状にして、天板をブリッジなしで支える。窓の上辺も45°なので、サポートなしで造形できる。
- 左右の足は同一形状。同じパーツを2個印刷し、片方は向きを反転して置く。

既定値は、高さ90mm（床から載せる物の底面まで）、支える長さ50mm、ズレ止めの壁の高さ10mm。荷重は1kg程度までを想定している。

## 構成

- メインSCAD: `leg.scad`
- 出力STL: `stl/leg.stl`（印刷用。2個印刷する）
- 組立STL: `stl/assembled.stl`（2本を組立位置に並べた確認用。印刷用ではない）
- 印刷用3MF: `leg.3mf`（A1 mini の1プレート分。2本をコの字の開いた側を向かい合わせて、プレート中央に並べる。足ごとに別オブジェクト）
- `render_stl.sh`: 上記のSTL2つと3MFを再生成する
- BOSL2: 使用していない

## パラメータ（MakerWorld Parametric Model Maker 対応）

| グループ | パラメータ | 既定値 | 内容 |
| --- | --- | --- | --- |
| 出力 | `part` | `pair` | `pair`: 2本を向かい合わせてA1 miniのプレート中央（90, 90）に並べた印刷用配置、`leg`: 1本、`assembled`: 組立確認 |
| 載せる物の底面 | `item_length` | 290 | 長辺。足と足の間隔を決める |
| | `item_width` | 48 | 短辺 |
| | `clearance` | 0.5 | 載せる物とズレ止めの壁の間の隙間（片側） |
| 足の寸法 | `leg_height` | 90 | 床から載せる物の底面までの高さ |
| | `leg_length` | 50 | 長辺方向に支える長さ（ズレ止めの壁を含む） |
| ズレ止めの壁 | `guide_height` | 10 | 高さ。0にすると壁なし |
| | `guide_thickness` | 3 | 厚さ |
| 構造 | `shell_thickness` | 2 | 柱の壁厚 |
| | `top_thickness` | 3 | 天板の厚さ |
| | `foot_flange` | 0 | 底面の外周に張り出すフランジの幅。ベッドから剥がれやすい場合に使う |
| 菱形窓 | `windows` | true | 窓の有無 |
| | `window_size` | 14 | 菱形の対角長 |
| | `window_strut` | 4 | 窓と窓の間に残す桟の幅 |
| | `window_edge` | 5 | 柱の角、下端、天井の立ち上がりから窓までの余白 |

`foot_flange` が0なら、各スライダーの範囲内で `pair` の配置が A1 mini のビルド範囲 180 × 180 × 180mm に収まる。フランジを付けると、配置の縦横がそれぞれフランジ幅の2倍以上広がる。ビルド範囲を超える場合は `leg` で1本ずつ出力する。

## 印刷上の注意

- 天面を上にした向きのまま、サポートなしで印刷する。
- 柱の底面は開いている（中空の筒）。
- 内部天井の寄棟より上は、モデル上は中実になっている。スライサーでは疎なインフィル（10〜15%程度）で埋めればよい。

## 再生成

```bash
./render_stl.sh
```

個別に出力する場合:

```bash
openscad --backend=manifold -D 'part="leg"' -o stl/leg.stl leg.scad
openscad --backend=manifold -D 'part="assembled"' -o stl/assembled.stl leg.scad
openscad --backend=manifold --enable=lazy-union -D 'part="pair"' -o leg.3mf leg.scad
```

`--enable=lazy-union` で書き出すと、トップレベルに並べた2本の足がそれぞれ別オブジェクトになる。
