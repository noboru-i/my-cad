- 生成済みSTL: `water_plant_holder.stl`
- スライサー用3MF: `water_plant_holder.scad.3mf`

## 再生成

```bash
openscad --render -o water_plant_holder.stl water_plant_holder.scad
```

これは旧配置のモデルであり、STLはモデル直下に保持している。
