# keyboard_trackpad_tray v5

Magic Keyboard と Magic Trackpad 2 をまとめて置くトレイ。03enterprise 製「Crispy Backboard PRO 2021」のように、トラックパッドをキーボード手前中央に置き、左右のリストレストがトラックパッドの両端に覆いかぶさる形を目指す。

v4 までは大きなベース板を切り分けて作っていた。v5 では、トラックパッド外枠を中心に、パーツを 1 つずつ設計して結合する作り方に変えている。

## 最終目的

- トラックパッド外枠、左右リストレスト、キーボード土台（左右分割）の 5 パーツで構成する
- 各パーツを Bambu Lab A1 mini（ビルドプレート 180 × 180mm）で印刷できる大きさに収める
- パーツ同士はダブテールで結合する
- キーボード手前端をトラックパッド奥端に重ねて、全体の奥行を詰める

## 現在の状況

| パーツ | 状況 |
|---|---|
| トラックパッド外枠 | 奥行をさらに 0.2mm 補正し、奥面に土台用のダブテール溝を追加した。ポート切り欠きは、下に床を残す形から上にブリッジを残す形に変えた（ケーブルを挿したまま上から被せるため）。再印刷が必要 |
| 左右リストレスト | 天面をトラックパッドと同じ傾斜にした。再印刷が必要 |
| キーボード土台 | 奥行を 0.7mm 補正し、周囲の壁をキーボードと同じ高さにした。枠とのダブテールを追加した。再印刷が必要 |

## 寸法ソース

- Magic Trackpad 2: 160 × 114.9 × 4.9–10.9mm（Apple / Wikipedia）
  - 外形は Lightning 版（2015年 / 2021年）と USB-C 版（2024年）で共通
  - 奥行の公称値 114.9mm は、手前のボタン部の出っ張りも含んだ値とみられる。実機では前後に遊びが出たため、`tp_d = 114.2` と 0.7mm 短くしている
  - コーナーRは世代で違う（2015年版は小さく、2021年以降は大きい）。ポケットを小さいRに合わせておけば、どの世代も収まる
  - 背面の配置（iFixit の分解写真より）: 充電ポートは中央、電源スイッチは手前から見て右奥
- Magic Keyboard: 279 × 114.9 × 4.1–10.9mm（Apple / Wikipedia）
  - 実機では前後に遊びが出たため、`kb_d = 114.2` と 0.7mm 短くしている
  - 背面の配置: 充電ポートは中央、電源スイッチは手前から見て右奥（右端からの距離は未実測）
- トレイ全体: 286 × 228.4mm（全幅は v4 と同じ。Magic Keyboard 279mm + 遊び + 左右リブ）

## 座標系

トラックパッド底面の手前左角が原点。X が幅方向、Y が奥行方向（奥が +Y）。
トラックパッド天面の高さは `tp_top_z(y)` で求まり、枠の天面とリストレストの覆い部分の下面はこの傾きに沿わせている。リストレストの天面（`rest_top_z(y)`）も同じ傾き。キーボード天面の高さは `kb_top_z(y)` で、土台の周囲の壁はこれに沿わせている。

### トラックパッド外枠

- トラックパッドを四方から囲う枠。天面はトラックパッド天面と面一
- 奥壁に充電ポートと電源スイッチ（下 2mm を残した U 字）の切り欠きがある。ポート切り欠きは床から高さ 8.9mm までのトンネルで、上に厚さ `tp_port_bridge_t`（2mm）のブリッジを残し、枠をリング状につなげて剛性を上げている。下が開いているので、ケーブルを挿したトラックパッドに枠を上から被せられる
- ポート上のブリッジ（幅 14mm）はそのまま印刷すればブリッジ印刷になり、サポート不要
- 左右外側面にリストレスト用のダブテール溝、奥面にキーボード土台用のダブテール凸がある

### リストレスト

- 天面はトラックパッドと同じ傾斜で手前が下がる（奥端 15mm、手前端約 9.2mm）。トラックパッドの左右端を `rest_tp_cover`（20mm）覆う
- 覆い部分の下面は、トラックパッド天面から `rest_tp_gap`（1mm）浮かせて傾きに沿わせている。天面と平行なので、覆い部分の厚さは約 3.7mm で一定
- 内側の奥を斜めにカットしている（Crispy Backboard PRO 2021 と同じ）
- 奥端はキーボード手前端の直前（y = 102.9）で終わる。奥面はキーボードの手前ストッパーを兼ねるので、面取りしていない
- 天面の縁は 45° の面取り（1.5mm）。反転印刷でベッド側になるため、R だとオーバーハングになる
- 印刷時は奥端の天面エッジを軸に傾き（約 3°）を戻して天面を水平にしてから反転する。覆い部分の下面も天面と平行なので、印刷向きでは水平になる

### キーボード土台

- キーボード載置面は高さ 12.5mm（`rest_h - kb_front_stop_h`）。リストレスト天面より 2.5mm 低く、リストレストの奥面がキーボードの手前ストッパーになる
- 土台自体はトラックパッドの上に張り出さない。キーボード本体がトラックパッドの奥端に `kb_tp_overlap`（11mm）重なる。張り出しがないので、そのままの向きでサポートなしで印刷できる
- キーボード底面と枠奥端の天面の隙間は約 1.2mm
- 周囲の壁はキーボードと同じ高さ（左右は 4.1→10.9mm の傾斜、奥は 10.9mm）。奥の壁はキーボード背面の充電ポートと電源スイッチの位置だけ載置面まで切り欠く
- リストレスト奥端の天面（15mm）は、キーボード手前端の天面（約 16.6mm）より約 1.6mm 低い。左右の壁の手前端とは段差になる
- 底面側に、トラックパッドのケーブルを背面へ通す溝（天井の幅 16 × 高さ 8mm）がある。枠のポート切り欠きの真後ろ。側面は 45° で底面に向かって広がる（底面での幅 32mm）ので、立てて印刷してもサポート不要
- 左右の分割位置は x = 105（トラックパッド中心から 25mm 右）。ケーブル溝を継ぎ目から外すため
- 中身は無垢の形状なので、スライサーのインフィル設定で軽くする

### 結合（ダブテール）

どれも上から差し込む向きなので、次の順に組み立てる。

1. トラックパッド外枠を置く
2. キーボード土台 左を上から差し込む（枠の奥面の凸が土台側の全高の溝に入る）
3. キーボード土台 右を上から差し込む（継ぎ目: 右側が凸、左側が全高の溝。枠の奥面にも同時に入る）
4. 左右リストレストを上から下ろす。枠の溝（リストレスト側が凸）と土台の凸（リストレスト側は下から開いた止まり溝）に同時に入る

- 枠↔リストレストのダブテールは、枠奥行の 45% と 80% の位置（y ≈ 50.7 / 96.0）。枠の手前側は低い（約 4.5mm）ので避けている
- 枠↔土台のダブテールは左右の土台に 1 つずつ（x ≈ 38 / 124）。枠側を凸にして、枠の奥壁が溝で細くならないようにしている。左は枠奥辺の直線部とポート切り欠きの間、右は継ぎ目とスイッチ切り欠きの間の中央
- `kb_tp_overlap` の上限は約 11mm。これを超えると、リストレスト奥端が y ≈ 96 のダブテールにかかる。重なりを増やすには `dt_y_ratios` を変えて枠を印刷し直す必要がある

## 主要パラメータ

| 変数 | 初期値 | 効果 |
|---|---|---|
| `tp_d` | 114.2 | トラックパッド奥行（公称 114.9 から補正） |
| `kb_d` | 114.2 | キーボード奥行（公称 114.9 から補正） |
| `tp_port_bridge_t` | 2 | 枠のポート切り欠きの上に残すブリッジの厚さ（切り欠きの高さは奥壁の天面から引いた 8.9mm） |
| `tp_corner_r` | 3 | トラックパッドのコーナーR（要実測） |
| `margin` | 0.5 | デバイス周囲の遊び（片側） |
| `frame_wall` | 7 | 枠の壁厚 |
| `frame_top_offset` | 0 | 枠天面をトラックパッド天面から下げる量 |
| `tray_w` | 286 | トレイ全幅。リストレストの幅とキーボード左右リブの幅はここから決まる |
| `rest_h` | 15 | リストレスト奥端の天面の高さ（手前はトラックパッドと同じ傾斜で下がる） |
| `rest_tp_cover` | 20 | リストレストがトラックパッド左右端を覆う量 |
| `rest_tp_gap` | 1 | 覆い部分とトラックパッド天面の隙間 |
| `rest_chamfer_d` | 20 | 内側奥の斜めカットの Y 方向長さ |
| `kb_tp_overlap` | 11 | キーボード手前端がトラックパッド奥端に重なる量（上限約 11） |
| `kb_front_stop_h` | 2.5 | リストレスト奥面が載置面から立ち上がる高さ。載置面の高さも決まる |
| `kb_port_x` / `kb_port_cut_w` | kb_w / 2 / 24 | キーボード充電ポートの位置（左端から）と奥壁の切り欠き幅 |
| `kb_switch_x` / `kb_switch_cut_w` | kb_w − 15 / 20 | キーボード電源スイッチの位置（左端から）と奥壁の切り欠き幅（要実測） |
| `kb_split_x` | 105 | キーボード土台の左右分割位置 |
| `kb_cable_w` / `kb_cable_h` | 16 / 8 | ケーブル溝の幅・高さ |
| `dt_root_w` / `dt_tip_w` / `dt_depth` | 8 / 11 / 4.5 | ダブテールの付け根幅・先端幅・深さ（全継手共通） |
| `dt_clearance` | 0.2 | ダブテール溝のクリアランス（片側） |

## 要実測

- `tp_corner_r`: トラックパッドのコーナーR
- `tp_switch_x`: トラックパッド電源スイッチの位置（右端から約 11mm と仮定）
- `tp_switch_cut_z`: スイッチの下端が 2mm より低い場合は下げる
- `kb_switch_x`: Magic Keyboard 背面の電源スイッチの位置（キーボード手前から見た左端基準。右端から約 15mm と仮定）。切り欠きは右端から 5〜25mm の範囲
- `tp_port_bridge_t`: トラックパッドのケーブルのプラグがポート上のブリッジ（下面は床から 8.9mm）に当たらないか

## メモ

- トラックパッドの電源スイッチは、キーボードの下に隠れる。操作するときはキーボードをずらす

## STL 生成と印刷

```bash
./render_stl.sh   # stl/ に 5 パーツと組立確認用の assembled.stl (印刷用ではない)、1 プレート分の 3MF を出力
```

- BOSL2 を使うため、ディレクトリに `BOSL2 -> ../lib/BOSL2` のシンボリックリンクがある
- `stl/assembled.stl` では、土台の左右が 1 つの塊になる。継ぎ目の平らな面が隙間 0 の突き合わせのため（ダブテール部分にはクリアランスがある）

### 1 プレート印刷（part=7）

`keyboard_trackpad_tray_v5.3mf` を Bambu Studio で開くと、5 パーツが別々のオブジェクトとして A1 mini のプレート（180 × 180mm）に並ぶ。`--enable=lazy-union` で書き出すと、トップレベルに並べた形状がそれぞれ別オブジェクトになる。

| パーツ | 向き | 高さ |
|---|---|---|
| トラックパッド外枠 | 平置き | 11.5mm |
| キーボード土台 左 | 奥面を下にして立てる。枠の奥に置く | 122.5mm |
| キーボード土台 右 | 右端面を下にして立てる。枠のポケットの中に置く | 122.5mm |
| 左右リストレスト | 外側面を下にして立てる。枠のポケットの中に置く | 83mm |

- 向きは、45° より寝た下向きの面（サポートが要る面）が少なくなるように選んだ。ケーブル溝は側面を 45° にしてあるので、どの向きでもサポート不要
- 45° より寝た下向きの面として残るのは、ダブテールの斜面（深さ 4.5mm、1 か所 30mm² 程度）と、ベッドに接する角の R だけ。土台 左の継ぎ目の溝、土台 右の枠用の溝とリストレスト用の凸、リストレストの土台用の溝が該当する
- 高さ 80〜120mm の薄いパーツを立てるので、ブリムを付ける
- オブジェクト名は OpenSCAD の既定（`OpenSCAD Model 1`〜`5`）になる。番号は上の表の順

### 試し刷り（軽量化）の設定

プロファイル「0.20mm Standard @BBL A1M」から、Strength タブの次の 2 項目だけを変える。

| 設定 | 既定値 | 試し刷り |
|---|---|---|
| Sparse infill density | 15% | 5% |
| Sparse infill pattern | Grid | Lightning |

- 土台とリストレストは中身の詰まった形なので、重さはほぼインフィルで決まる。Lightning は天面を支える所にだけインフィルを入れるので、材料と時間が大きく減る（強度は低い）
- Wall loops は減らさない。ダブテールやポケットの寸法精度は壁で決まるので、はめ合いのテストにならなくなる
- インフィル 0% は不可。土台の天面を支えるものがなくなり、垂れる
