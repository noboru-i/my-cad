# keyboard_trackpad_tray v5

Magic Keyboard と Magic Trackpad 2 をまとめて置くトレイ。03enterprise 製「Crispy Backboard PRO 2021」のように、トラックパッドをキーボード手前中央に置き、左右のリストレストがトラックパッドの両端に覆いかぶさる形を目指す。

v4 までは大きなベース板を切り分けて作っていた。v5 では、トラックパッド外枠を中心に、パーツを 1 つずつ設計して結合する作り方に変えている。

## 最終目的

- トラックパッド外枠、左右リストレスト、キーボード土台の 3 系統のパーツで構成する
- 各パーツを Bambu Lab A1 mini（ビルドプレート 180 × 180mm）で分割なしに印刷できる大きさに収める
- パーツ同士はダブテール等の継手で結合する

## 現在の状況

| パーツ | 状況 |
|---|---|
| トラックパッド外枠 | 初版（壁厚 6mm）を試作し、奥行を補正（`tp_d`）。その後、壁厚 7mm 化とダブテール溝を追加したため再印刷が必要 |
| 左右リストレスト | 設計済み（未印刷） |
| キーボード土台 | 未着手 |

## 寸法ソース

- Magic Trackpad 2: 160 × 114.9 × 4.9–10.9mm（Apple / Wikipedia）
  - 外形は Lightning 版（2015年 / 2021年）と USB-C 版（2024年）で共通
  - 奥行の公称値 114.9mm は、手前のボタン部の出っ張りも含んだ値とみられる。実機では前後に遊びが出たため、`tp_d = 114.4` と 0.5mm 短くしている
  - コーナーRは世代で違う（2015年版は小さく、2021年以降は大きい）。ポケットを小さいRに合わせておけば、どの世代も収まる
- 背面の配置（iFixit の分解写真より）: 充電ポートは中央、電源スイッチは手前から見て右奥
- トレイ全幅 286mm は v4 と同じ（Magic Keyboard 279mm + 余裕）

## 座標系

トラックパッド底面の手前左角が原点。X が幅方向、Y が奥行方向（奥が +Y）。
トラックパッド天面の高さは `tp_top_z(y)` で求まり、枠の天面とリストレストの覆い部分の下面はこの傾きに沿わせている。

## パーツ構成（`part` パラメータ）

| part | パーツ | 外形 | 説明 |
|---|---|---|---|
| 0 | Assembly | – | プレビュー用。組み立てた状態。`show_devices=true` でトラックパッドのダミーを重ねる |
| 1 | TrackpadFrame | 175 × 129.4 × 4.5–11.3mm | トラックパッドを四方から囲う枠。天面はトラックパッド天面と面一。奥壁に充電ポート（全高）と電源スイッチ（下 2mm を残した U 字）の切り欠きがある。左右外側面にダブテール溝がある |
| 2 | WristRest_L | 83 × 129.4 × 15mm | 左リストレスト。上下反転した印刷向きで出力する |
| 3 | WristRest_R | 83 × 129.4 × 15mm | 右リストレスト（左のミラー）。上下反転した印刷向きで出力する |

### リストレストの形

- 天面は高さ 15mm でフラット。トラックパッドの左右端を `rest_tp_cover`（20mm）覆う
- 覆い部分の下面は、トラックパッド天面から `rest_tp_gap`（1mm）浮かせて傾きに沿わせている。覆い部分は奥ほど薄く、最薄部は約 2.7mm
- 内側の奥を斜めにカットしている（Crispy Backboard PRO 2021 と同じ）。右リストレストは電源スイッチの切り欠きの上も覆わない
- 天面の縁は 45° の面取り（1.5mm）。反転印刷でベッド側になるため、R だとオーバーハングになる

### 結合（ダブテール）

- 凸をリストレスト側、溝を枠の左右外側面に付けている。枠側に凸を付けると枠の幅が 180mm を超えるため
- 溝は枠の全高を貫通している。リストレストを上から差し込むと、前後・左右のズレが止まる
- 枠の手前側は低い（約 4.5mm）ので、ダブテールは枠奥行の 45% と 80% の位置に置いている

## 主要パラメータ

| 変数 | 初期値 | 効果 |
|---|---|---|
| `tp_d` | 114.4 | トラックパッド奥行（公称 114.9 から補正） |
| `tp_corner_r` | 3 | トラックパッドのコーナーR（要実測） |
| `margin` | 0.5 | トラックパッド周囲の遊び（片側） |
| `frame_wall` | 7 | 枠の壁厚 |
| `frame_top_offset` | 0 | 枠天面をトラックパッド天面から下げる量 |
| `tray_w` | 286 | トレイ全幅。リストレストの幅はここから決まる |
| `rest_h` | 15 | リストレスト天面の高さ |
| `rest_tp_cover` | 20 | リストレストがトラックパッド左右端を覆う量 |
| `rest_tp_gap` | 1 | 覆い部分とトラックパッド天面の隙間 |
| `rest_chamfer_d` | 20 | 内側奥の斜めカットの Y 方向長さ |
| `dt_root_w` / `dt_tip_w` / `dt_depth` | 8 / 11 / 4.5 | ダブテールの付け根幅・先端幅・深さ |
| `dt_clearance` | 0.2 | ダブテール溝のクリアランス（片側） |

## 要実測

- `tp_corner_r`: トラックパッドのコーナーR
- `tp_switch_x`: 電源スイッチの位置（右端から約 11mm と仮定）
- `tp_switch_cut_z`: スイッチの下端が 2mm より低い場合は下げる

## STL 生成と印刷

```bash
./render_stl.sh   # stl/trackpad_frame.stl, stl/wrist_rest_l.stl, stl/wrist_rest_r.stl
```

- 枠はそのままの向きで、リストレストは天面をベッドに付けた向き（出力済み）で印刷する。どちらもサポート不要
- BOSL2 を使うため、ディレクトリに `BOSL2 -> ../lib/BOSL2` のシンボリックリンクがある
