# keyboard_trackpad_tray v2

Magic Keyboard + Magic Trackpad トレイ。全パーツが厚さ **5mm** の 2D 輪郭プレートで、十字相欠きと蟻継ぎで組む格子（エッグクレート）構造。**Bambu Lab A1 mini の 2 プレートで全パーツを印刷できる。**

## 初回印刷のフィードバックによる再設計

1. **継ぎ目の剛性強化**: 板厚を 3mm → 5mm に増し、蟻継ぎの継ぎ目をすべて交差スロットの真上に移動した。直交する部材がスロットを貫通して継ぎ目を両側から挟むため、組み上げ後は継ぎ目単体に力がかからない（A1/A2 がズレる問題の対策）
2. **トラックパッドは机に直置き**: 支持リブを廃止し、格子に開けたポケットへ落とし込む。後方に新設したストップレール（R2）が後ろズレを防ぎ、キーボードデッキ前縁の支持も兼ねる。クリック感も机直置きで改善
3. **全体を低く**: キーボード支持面 22.6mm → **12.6mm**（トラックパッドとの上下差 12.6mm は維持）。手置き板の上面は 12mm で、トラックパッド面（前縁 4.9mm）より高い
4. **ポケットを詰めた**: キーボード奥行の遊びを −3mm（前後計 1mm）、トラックパッド横方向の遊びを −2mm（左右計 1.2mm）

## 寸法ソース

2026-06-22 に Apple Store の Tech Specs から取得。

- Magic Keyboard (USB-C): 278.9 × 114.9 × 4.1–10.9 mm
- Magic Trackpad (USB-C): 160.0 × 114.9 × 4.9–10.9 mm

## パーツ構成（21 ピース）

各ピースには識別コードが彫り込んである（深さ 0.6mm）。同じ記号同士を蟻継ぎで連結する。数字は 1=手前 / 2=奥、L/C/R は左/中央/右。

| 刻印 | ピース | 数 | 説明 |
|---|---|---|---|
| A1 / A2 | outer_front / outer_rear | 各2 | 外壁リブ（キーボード横ストップ・前リップ・手置き板ほぞ付き） |
| B1 / B2 | stop_front / stop_rear | 各2 | トラックパッド横壁 + キーボード支持リブ |
| C | center | 1 | 中央リブ（キーボード下のみ。継ぎ目なし） |
| R1L / R1C / R1R | front_rail_* | 各1 | 前縁レール（トラックパッド前リップ・手置き板受け・接地パッド） |
| R2 | tpstop_rail | 1 | トラックパッド後方ストップ兼キーボード前縁支持。中央に USB-C プラグ用アーチ |
| R3L / R3R | mid_rail_* | 各1 | 中間レール（ケーブルアーチ付き） |
| R4L / R4R | rear_rail_* | 各1 | 後部レール（ケーブルアーチ・接地パッド付き） |
| WL / WR | wrist_l / wrist_r | 各1 | 手置き板。外壁リブの通しほぞと内縁の切り欠きで格子をロック（刻印は裏面） |

**継ぎ目の位置**: リブ（A/B）は R2 レールのスロット内、前縁レール（R1）は B リブのスロット内、R3/R4 は中央リブ C のスロット内で継ぐ。差し込むと交差部材が継ぎ目を貫通してロックされる。

## STL 生成と印刷

```bash
./render_stl.sh   # stl/plate1.stl, stl/plate2.stl
```

- 各プレートは 178×178mm 以内に配置済み（`part="check_fit1/2"` が空レンダリングになることで保証）
- 推奨: 0.2mm layer, 4 walls, infill 40% 以上
- 全パーツ平置き・サポート不要。ブリムなし推奨（ピース間隔 1.5mm のため）

## 組み立て

1. Y リブを前後で蟻継ぎ連結（A1+A2 を2組、B1+B2 を2組）。蟻継ぎは板厚方向へ横からスライドさせて噛ませる
2. 前縁レールを連結（R1L + R1C + R1R）。R3L+R3R、R4L+R4R も連結
3. レール（R1、R2、R3、R4）を手前から順に置き、リブを上から十字に差し込む。A を両外、B をその内側、C（中央リブ）は R3 / R4 のみに差さる。**リブの継ぎ目が R2 のスロットに、レールの継ぎ目がリブのスロットに入ることを確認**
4. 手置き板 WL / WR を上から押し込む。外壁リブの通しほぞが穴に、B リブのほぞが内縁の切り欠きに入り、格子全体がロックされる
5. トラックパッドを前中央のポケットへ落とす（机に直接接地）。キーボードは奥の一段高いデッキに載せる

きつい場合は `slot_clearance` / `splice_clearance` / `tenon_clearance` を増やして再出力する。

## メモ

- トラックパッドの充電プラグは R2 中央のアーチを通してキーボード下へ差し、ケーブルは R3 / R4 のアーチ（x=+25）から背面へ抜ける。キーボードは背面からそのまま充電可
- 手置き板の上面（12mm）はトラックパッド面より高い（意図した設計）
- 検証用 part: `assembly`（デバイスの半透明ダミー付き）/ `check_fit1` / `check_fit2` / `check_interference`
