# keyboard_trackpad_tray v2

Magic Keyboard + Magic Trackpad トレイの再設計版。全パーツが厚さ 3mm の 2D 輪郭プレートで、レーザーカットキットのように十字相欠き・蟻継ぎ・通しほぞで組む格子（エッグクレート）構造。**Bambu Lab A1 mini の 2 プレートで全パーツを印刷できる。**

## v1 からの変更点

- 4 プレート → **2 プレート**（`plate1` / `plate2` にレイアウト済み）
- **2 段デッキ構造**: キーボード支持面（22.6mm）がトラックパッド後端（厚 10.9mm）の上に張り出し、v1 で干渉していた奥行き方向の重なり約 24mm を解消
- 底面フラット板を廃止し、机に接するのは前後レールの接地パッドのみ（内側リブは 0.4mm 浮かせてガタつき防止）
- 充電ケーブルは格子内の空間を通す（mid / rear レールのアーチ穴 x=+25 経由で背面へ）。上面スリットは廃止
- ネジ・接着剤なしの差し込み組み立ては継続

## 寸法ソース

2026-06-22 に Apple Store の Tech Specs から取得（v1 と同じ）。

- Magic Keyboard (USB-C): 278.9 × 114.9 × 4.1–10.9 mm
- Magic Trackpad (USB-C): 160.0 × 114.9 × 4.9–10.9 mm

## パーツ構成（20 ピース）

| ピース | 数 | 説明 |
|---|---|---|
| outer_front / outer_rear | 各2 | 外壁リブ（キーボード横ストップ・手置き板ほぞ付き）。前後を蟻継ぎで連結 |
| stop_front / stop_rear | 各2 | トラックパッド横ストップ壁 + キーボード支持リブ |
| center_front / center_rear | 各1 | 中央リブ（後端の充電ポート前は低くしてプラグ逃げ） |
| stub | 2 | トラックパッド前半分の補助支持リブ（x=±45） |
| front/tpmid/mid/rear_rail の l/r | 各1 | 横レール4系統。左右を蟻継ぎで連結 |
| wrist_l / wrist_r | 各1 | 手置き板。外壁リブの通しほぞで固定 |

## STL 生成と印刷

```bash
./render_stl.sh   # stl/plate1.stl, stl/plate2.stl
```

- 各プレートは 178×178mm 以内に配置済み（`part="check_fit1/2"` が空レンダリングになることで保証）
- 推奨: 0.2mm layer, 3–4 walls, infill 40% 以上（部材が薄いのでほぼソリッドになる）
- 全パーツ平置き・サポート不要。ブリムなし推奨（ピース間隔 1.5mm のため）

## 組み立て

1. 横レール4系統をそれぞれ左右で蟻継ぎ連結（front/tpmid は x=+15、mid/rear は x=-25 で継ぐ）
2. Y リブ（outer/stop/center）を前後で蟻継ぎ連結
3. レールのスロット（上から）にリブのスロット（下から）を十字に差し込む。スタブ 2 本は front / tpmid レールへ
4. 手置き板のほぞ穴を外壁リブ上の通しほぞに合わせて上から押し込む（これが格子全体のロックを兼ねる）
5. トラックパッドを前中央に落とし、後端をキーボードデッキの下へ差し込む。キーボードは奥の一段高いデッキに載せる

きつい場合は `slot_clearance` / `splice_clearance` / `tenon_clearance` を増やして再出力する。

## メモ

- トラックパッドの後方ストップは意図的に無い（差し込み式のため）。使用中に後ろへずれる場合は下面に滑り止めを貼る
- キーボードがリブのエッジに直接載るため、滑るようならリブ上面へシリコンバンパーを貼る
- 充電はどちらも設置したまま可能。キーボードはトレイ背面からそのまま、トラックパッドはキーボード下の空間にプラグが収まり、ケーブルは格子内 → mid/rear レールのアーチ → 背面へ抜ける
- 検証用 part: `assembly`（デバイスの半透明ダミー付き）/ `check_fit1` / `check_fit2` / `check_interference`
